# Brand fonts

Latin WOFF2 subsets of Instrument Sans (400–700) and JetBrains Mono (500–700), matching Seamlift’s brand-page fonts. These files come from Seamlift’s existing Next.js Google Fonts build and are self-hosted so building the site requires no font downloads.

Both are licensed under the SIL Open Font License. Their license files are included alongside the fonts.

Sources: https://github.com/google/fonts/tree/main/ofl/instrumentsans and https://github.com/google/fonts/tree/main/ofl/jetbrainsmono.
